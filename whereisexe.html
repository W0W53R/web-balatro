Where is the .exe file?

Steam (Windows, Linux, Steam Deck)

In your Steam library, right click Balatro, click Manage, then Browse local files. Balatro.exe is in the folder that opens. The default locations are:

  • Windows: C:\Program Files (x86)\Steam\steamapps\common\Balatro\Balatro.exe
  • Linux / Steam Deck: ~/.local/share/Steam/steamapps/common/Balatro/Balatro.exe

Steam (macOS)

Open the game's folder the same way. The game is packaged as Balatro.app: right click it, choose Show Package Contents, and open Contents/Resources. Pick the .love file in there.

Other stores

Some stores (such as the Xbox app / PC Game Pass) protect their game files, so they can't be used here.

Mobile / Console

Accessing the game files on mobile or on console requires a rooted or jailbroken device.

Moving your desktop save

You can import a save from the desktop game. Zip the save folder (or the files inside it), then load a version on the main page and use Save Data → Upload.

  • Windows: %AppData%\Balatro
  • macOS: ~/Library/Application Support/Balatro
  • Linux / Steam Deck (Proton): ~/.local/share/Steam/steamapps/compatdata/2379780/pfx/drive_c/users/steamuser/AppData/Roaming/Balatro

The folder contains settings.jkr and numbered profile folders (1, 2, 3). Saves made here can be downloaded and copied back the same way.
